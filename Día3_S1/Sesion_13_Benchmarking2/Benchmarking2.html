Introducción

Este sección describe paso a paso el procedimiento de benchmarking aplicado a cada iteración del modelo bayesiano de área multinomial. El objetivo es garantizar que las estimaciones modeladas sean coherentes con los totales agregados obtenidos directamente de la encuesta, preservando la consistencia interna por dominio.

Objetivo general

  • Ajustar probabilidades multinomiales predichas por un modelo bayesiano para que sean coherentes con los totales directos observados en la encuesta.

  • Mantener coherencia entre:

    • Totales de Ocupados, Desocupados e Inactivos por dominio (DAM).
    • Tamaños poblacionales por dominio.

  • Obtener, a partir de las cadenas calibradas:

    • Medias posteriores.
    • Desviaciones estándar.
    • Coeficientes de variación (CVE).
    • Intervalos creíbles.

Notación básica

  • Índices:

    • \(k = 1,\dots,K\): unidades de post-estrato o dominios finos (ej. municipios).

    • \(d = 1,\dots,D\): dominios agregados (DAM).

    • \(l = 1,\dots,L\): iteraciones de la cadena MCMC.

    • \(c \in \{O, D, I\}\): Ocupado, Desocupado, Inactivo.

  • Cantidades:

    • \(N_k\): población total del post-estrato \(k\).

    • \(p_{k,c}^{(l)}\): probabilidad predicha para categoría \(c\) en iteración \(l\).

    • \(Y_{k,c}^{(l)} = N_k\,p_{k,c}^{(l)}\): “cuasi-total” basado en el modelo.

Totales directos (objetivos de calibración)

A partir de la encuesta se tienen, por dominio \(d\):

  • Totales directos por categoría:

    \[ T_{d,O}^{DIR}, \quad T_{d,D}^{DIR}, \quad T_{d,I}^{DIR} \]

  • Tamaño poblacional directo:

    \[ N_d^{DIR} \]

Estos valores definen las restricciones de benchmarking que deben cumplir las cadenas ajustadas.

Estructura de las cadenas del modelo

Para cada iteración \(l\) de la MCMC, el modelo genera probabilidades:

\[ \big(p_{k,O}^{(l)},\ p_{k,D}^{(l)},\ p_{k,I}^{(l)}\big), \quad k=1,\dots,K. \]

Estas probabilidades pueden representarse como una matriz:

\[ \Theta^{(l)} = \begin{bmatrix} p_{1,O}^{(l)} & p_{1,D}^{(l)} & p_{1,I}^{(l)} \\ \vdots & \vdots & \vdots \\ p_{K,O}^{(l)} & p_{K,D}^{(l)} & p_{K,I}^{(l)} \end{bmatrix} \]

La función de benchmarking trabaja iteración por iteración sobre esta matriz.

Paso 1: Construcción de la base por iteración

Para una iteración fija \(l\), se arma una tabla conceptual:

\[ \Big\{ \text{dam}_k,\ N_k,\ p_{k,O}^{(l)},\ p_{k,D}^{(l)},\ p_{k,I}^{(l)} \Big\}_{k=1}^K. \]

Esta tabla vincula:

  • La identificación del dominio (\(\text{dam}_k\)).
  • La población \(N_k\).
  • Las probabilidades predichas para cada categoría.

A partir de aquí se construyen las matrices de calibración.

Paso 2: Matriz de indicadores por dominio

Se define la matriz indicadora por dominio (DAM):

\[ X_{\text{DAM}}(k,d) = \mathbb{I}\big(\text{unidad } k \in \text{DAM } d\big), \]

con:

  • Filas: post-estratos \(k = 1,\dots,K\). (municipios)
  • Columnas: dominios \(d = 1,\dots,D\).

Esta matriz permite agrupar sumas por DAM, tanto de población como de totales de categorías.

Paso 3: Matriz de calibración para Desocupados

Para la categoría Desocupado se construye una matriz \(X_s^{(D)}\) que concatena:

  • Parte de denominadores:

    \[ X_{\text{DAM}}(k,d) \quad \Rightarrow \quad \text{población por DAM} \]

  • Parte de numeradores modelo-basados:

    \[ X_{\text{DAM}}(k,d)\,p_{k,D}^{(l)} \quad \Rightarrow \quad \text{Desocupados modelo-basados por DAM} \]

De forma matricial:

\[ X_s^{(D)} = \Big[\, X_{\text{DAM}} \ \big|\ X_{\text{DAM}} \odot p_{\cdot,D}^{(l)} \,\Big], \]

donde \(\odot\) denota el producto elemento a elemento.

Paso 4: Totales objetivo para Desocupados

El vector de totales directos asociado a \(X_s^{(D)}\) es:

\[ t^{DIR}_{(D)} = \big( N_1^{DIR},\dots,N_D^{DIR},\, T_{1,D}^{DIR},\dots,T_{D,D}^{DIR} \big)^\top. \]

Las condiciones de calibración que se imponen son:

\[ \sum_{k} g_k^{(l,D)} \, N_k\, X_{\text{DAM}}(k,d) = N_d^{DIR}, \]

\[ \sum_{k} g_k^{(l,D)} \, N_k\, p_{k,D}^{(l)}\, X_{\text{DAM}}(k,d) = T_{d,D}^{DIR}, \]

para todo dominio \(d\).

Aquí \(g_k^{(l,D)}\) son los factores de calibración asociados a la categoría Desocupado en la iteración \(l\).

Paso 5: Matriz y totales para Ocupados

Análogamente, para la categoría Ocupado:

\[ X_s^{(O)} = \Big[\, X_{\text{DAM}} \ \big|\ X_{\text{DAM}} \odot p_{\cdot,O}^{(l)} \,\Big], \]

y el vector de totales directos:

\[ t^{DIR}_{(O)} = \big( N_1^{DIR},\dots,N_D^{DIR},\, T_{1,O}^{DIR},\dots,T_{D,O}^{DIR} \big)^\top. \]

Las condiciones:

\[ \sum_{k} g_k^{(l,O)} \, N_k\, X_{\text{DAM}}(k,d) = N_d^{DIR}, \]

\[ \sum_{k} g_k^{(l,O)} \, N_k\, p_{k,O}^{(l)}\, X_{\text{DAM}}(k,d) = T_{d,O}^{DIR}. \]

Paso 6: Solución de calibración

En cada iteración \(l\), se resuelven problemas de calibración del tipo:

\[ \sum_{k} g_k^{(l)} N_k\, \mathbf{x}_k = \mathbf{t}^{DIR}, \]

bajo una forma funcional para los factores:

  • Método lineal:
    \[ g_k^{(l)} = 1 + \lambda^{(l)\top} \mathbf{x}_k \]

  • Método logit (recomendado):
    \[ g_k^{(l)} = \frac{\exp\big(\lambda^{(l)\top}\mathbf{x}_k\big)} { \overline{w}\ + \exp\big(\lambda^{(l)\top}\mathbf{x}_k\big) }, \] asegurando positividad y estabilidad numérica.

En la práctica, la función de calibración numérica encuentra \(\lambda^{(l)}\) y de ahí se obtienen los \(g_k^{(l)}\).

Paso 7: Probabilidades ajustadas por iteración

Una vez obtenidos los factores de calibración:

  • Para Ocupados:

    \[ p_{k,O}^{(l),\text{bench}} = g_k^{(l,O)}\, p_{k,O}^{(l)}. \]

  • Para Desocupados:

    \[ p_{k,D}^{(l),\text{bench}} = g_k^{(l,D)}\, p_{k,D}^{(l)}. \]

  • Para Inactivos, se usa la restricción de suma 1:

    \[ p_{k,I}^{(l),\text{bench}} = 1 - \big(p_{k,O}^{(l),\text{bench}} + p_{k,D}^{(l),\text{bench}}\big). \]

Así, para cada iteración \(l\) se obtiene un conjunto de probabilidades multinomiales ajustadas por unidad \(k\).

Función benchmark_mcmc_multinomial()

La función de benchmarking produce, conceptualmente:

  • Un conjunto de iteraciones \(l = 1,\dots,L\), en las que la calibración converge.

  • Para cada iteración y unidad \(k\):

    • Probabilidades ajustadas: \[ p_{k,O}^{(l),\text{bench}},\quad p_{k,D}^{(l),\text{bench}},\quad p_{k,I}^{(l),\text{bench}}. \]

  • Estas probabilidades cumplen, por construcción, los totales directos por DAM en términos de numeradores y denominadores.

Se obtiene así una muestra posterior de tamaño \(L\) de las probabilidades multinomiales ya benchmarkeadas.

Paso 8: Resumen posterior

La función resumir_bench_multinomial() toma como insumo todas las iteraciones válidas y construye, para cada dominio \(d\) y categoría \(c\), la colección:

\[ \Big\{ \theta_{d,c}^{(l)} \Big\}_{l=1}^{L}, \]

donde \(\theta_{d,c}^{(l)}\) puede interpretarse como:

  • una tasa media ajustada por DAM (agregando los \(k\) que pertenecen a \(d\)), o
  • cualquier funcional de las probabilidades ajustadas dentro del dominio.

Estadísticos resumen por dominio y categoría

Para cada par \((d,c)\), se calculan:

  • Media posterior:

    \[ \hat{\theta}_{d,c} = \frac{1}{L}\sum_{l=1}^{L}\theta_{d,c}^{(l)}. \]

  • Desviación estándar posterior:

    \[ \widehat{\text{sd}}(\theta_{d,c}) = \sqrt{ \frac{1}{L-1}\sum_{l=1}^{L} \big(\theta_{d,c}^{(l)} - \hat{\theta}_{d,c}\big)^2 }. \]

  • CVE:

    \[ \text{CVE}_{d,c} = 100 \cdot \frac{\widehat{\text{sd}}(\theta_{d,c})}{\hat{\theta}_{d,c}}. \]

Intervalos creíbles

Para un nivel de credibilidad \(1-\alpha\), se obtienen los cuantiles empíricos:

\[ \text{LCI}_{d,c} = q_{\alpha/2} \big(\{\theta_{d,c}^{(l)}\}\big), \quad \text{UCI}_{d,c} = q_{1-\alpha/2} \big(\{\theta_{d,c}^{(l)}\}\big), \]

donde \(q_{\tau}\) denota el cuantíl de orden \(\tau\).

Estos intervalos resumen la incertidumbre posterior después de aplicar el benchmarking.

Salida resumida

La tabla final producida a nivel conceptual por resumir_bench_multinomial() contiene, para cada dominio \(d\) y categoría \(c\):

  • Identificador del dominio (ej. dam).
  • Nombre de la categoría (Ocupado, Desocupado, Inactivo).
  • Estimador puntual \(\hat{\theta}_{d,c}\).
  • Error estándar \(\widehat{\text{sd}}(\theta_{d,c})\).
  • CVE \(\text{CVE}_{d,c}\).
  • Intervalo creíble: \([\text{LCI}_{d,c}, \text{UCI}_{d,c}]\).

Conclusión

  • El proceso combina modelos multinomiales bayesianos con calibración por dominios para asegurar coherencia con totales directos.

  • benchmark_mcmc_multinomial():

    • ajusta las cadenas iteración por iteración,
    • impone restricciones de benchmarking,
    • produce probabilidades multinomiales coherentes.

  • resumir_bench_multinomial():

    • toma la muestra posterior ya calibrada,
    • calcula medidas de tendencia central y dispersión,
    • provee una salida estándar para análisis y reporte.

Este enfoque integra de forma natural el benchmarking en el flujo MCMC de estimación en áreas pequeñas para variables multinomiales del mercado laboral.
