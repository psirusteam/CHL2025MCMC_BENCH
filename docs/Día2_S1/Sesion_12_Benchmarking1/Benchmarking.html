Benchmarking ejemplificado en Modelos de Área para pobreza

Motivación

En modelos de área (por ejemplo, Fay–Herriot), las estimaciones para los dominios:

  • Pueden presentar incoherencias entre niveles geográficos

  • Requieren ajuste para cumplir identidades contables.

El benchmarking consiste en un ajuste estético para que las estimaciones modelo cumplan un total conocido, manteniendo al mismo tiempo la estructura relativa del predictor original.

Idea general

Sea:

  • \(\hat{P}_d\): estimación del modelo para el dominio \(d\);
  • \(N_d\): población del dominio;
  • \(T^{DIR}\): total observado directamente (por encuesta o censo).

El modelo produce:

\[ \hat{T}^{SAE} = \sum_{d=1}^D N_d , \hat{P}_d \]

pero no garantiza:

\[ \hat{T}^{SAE} = T^{DIR}. \]

Por ello, buscamos nuevos valores \(\tilde{P}_d\) tales que:

\[ \sum_d N_d \tilde{P}_d = T^{DIR}. \]

Enfoque de calibración

Se define una función que ajusta cada predictor:

\[ \tilde{P}_d = g_d \times \hat{P}_d, \]

donde los coeficientes \(g_d\) se obtienen mediante un método de calibración (lineal, logit, raking, etc.).

Se plantea una restricción:

\[ \sum_d N_d \times g_d \times \hat{P}_d = T^{DIR}. \]

Benchmarking mediante calibración lineal

Implementamos:

  • Predicciones modelo por dominio (p. ej., pobreza);

  • Tamaños poblacionales \(N_d\);

  • Total nacional directo observado.

Luego, calibramos para encontrar la serie ajustada \(g_d\).

Ejemplo reproducible

Datos base del ejemplo

# Vector con tasas predichas por el modelo para cada municipio (entre 0 y 1)
# Estas tasas podrían provenir de cualquier modelo: logístico, beta-binomial,
# Fay-Herriot, MCMC, etc.
y_pred <- c(0.35, 0.42, 0.28, 0.70)

# Tamaño poblacional por municipio
N_mpio <- c(500, 600, 400, 200)

# Suma de pobres predicha por el modelo sin benchmarking
sum(y_pred * N_mpio)
[1] 679

Total directo observado a nivel nacional

Pobreza_dir <- c(1700, 700)

Matriz de calibración

La calibración usa la matriz:

\[ X_s = \begin{bmatrix} 1 & \hat{P}_1 \\ 1 & \hat{P}_2 \\ \vdots & \vdots \\ 1 & \hat{P}_D \end{bmatrix} \]

y los totales conocidos:

\[ T = \begin{bmatrix} \sum_d N_d \\ T^{DIR} \end{bmatrix} \]

Código de R

Xs <- cbind(1 , y_pred)

Cálculo de factores de calibración

Código de R

gk <- calib(
  Xs = Xs,
  total = Pobreza_dir,
  d = N_mpio,
  method = "linear"
)

gk
[1] 0.9589041 1.0171233 0.9006849 1.2500000

Estimación calibrada por dominio

Código de R

# Pobreza calibrada por municipio
y_bench <- gk * y_pred
y_bench
[1] 0.3356164 0.4271918 0.2521918 0.8750000

Validación: total nacional

Validación de consistencia

tot_pobreza_bench <- y_bench * N_mpio
tot_pobreza_bench
[1] 167.8082 256.3151 100.8767 175.0000
tot_pobreza_bench Pobreza_dir diff
700 700 0

Resultado

Validación de consistencia

df_plot <- tibble(

Conclusiones

  • El benchmarking es un paso obligatorio cuando se requiere coherencia nacional.

  • Su implementación es sencilla mediante calib().

  • Es compatible con FH, MCMC y estimadores bayesianos.

  • Permite producir series armonizadas para tabulados oficiales.
